# 🎬 Movie Rental Analysis | SQL & Power BI

## 📌 Project Overview
This project focuses on analyzing movie rental data to understand rental performance, customer behavior, actor popularity, and revenue trends using SQL and Power BI.

The project transforms raw data into meaningful insights through SQL queries, DAX calculations, and interactive Power BI dashboards.

## 🛠️ Tools & Technologies
- SQL – Data extraction, filtering, joins, and analysis.
- Power BI – Data visualization and dashboard development.
- DAX – Calculated measures and KPIs.
- Excel – Data handling and preparation.

## 🎯 Project Objectives
- Analyze total rental revenue.
- Identify popular actors based on movie rentals.
- Analyze revenue generated by actors.
- Understand customer rental behavior.
- Analyze movie categories and rental trends.
- Identify top-performing movies.

## 📊 Key Performance Indicators (KPIs)
1. Total Rental Revenue
2. Total Rentals
3. Average Rental Rate
4. Actor Popularity
5. Revenue by Category
6. Customer Analysis
7. Movie Rental Frequency

## 📈 Dashboard Insights
The Power BI dashboard provides insights into:
- Actor Popularity Analysis
- Revenue Analysis
- Customer Distribution
- Category-wise Revenue
- Movie Rental Trends
- Top Movies Analysis

## 💡 Key Learnings
- Practiced SQL joins and queries.
- Developed DAX measures in Power BI.
- Created relationships between multiple tables.
- Improved data modeling skills.
- Designed interactive dashboards.
- Converted raw data into business insights.
